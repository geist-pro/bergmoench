# Bergmönch

A flashcard app for iOS, macOS and Android. It opens Anki decks (`.apkg`), schedules reviews with
FSRS, and keeps everything on your device. It is built on Anki's own Rust backend, so a deck
behaves the way it does in Anki.

Site and downloads: <https://apps.geist.pro/bergmoench/>

Bergmönch is made by [GEIST](https://geist.pro), the Human-Centered Information Systems group at
TU Clausthal. It is not affiliated with Anki or AnkiWeb.

## What works

- Import any `.apkg`; three course decks from TU Clausthal are offered on first run
  ([Programmieren](https://github.com/geist-pro/deck-programmieren), in German and English, and
  [Cooperation Systems](https://github.com/geist-pro/deck-cooperation-systems)).
- Review with two buttons (Forgot / Got it) or Anki's four, undo, flags, bury, suspend, typed answers
  where a deck asks for them, audio and text-to-speech.
- Home shows today's minutes, a five-week study calendar and your retention against the target.
  There is no streak counter.
- An exam date per deck caps the intervals so that reviews still happen before the exam.
- Browse and search, card info, statistics, a workload preview for the retention target.
- Reading settings (text size, weight, line spacing), light and dark themes, a home-screen widget
  and an optional daily reminder.
- Sync with a self-hosted Anki sync server. AnkiWeb is not supported; its terms do not allow
  third-party clients.

The defaults and the studies behind them are listed in [docs/science-defaults.md](docs/science-defaults.md).

## Layout

| Path | What |
|---|---|
| `apps/apple` | SwiftUI app for iOS and macOS, widget, tests. The Xcode project is generated by XcodeGen from `project.yml`. |
| `apps/android` | Jetpack Compose app (arm64). |
| `core/ffi` | `kartei-core`: Anki's Rust backend plus a five-function C interface. Every call is a protobuf message in and out. |
| `core/gen` | Swift, Kotlin and Java code generated from Anki's proto files. Do not edit. |
| `core/web`, `core/themes.json` | Card CSS/JS and the colour themes shared by both apps. |
| `content/courses` | Builds the bundled course decks from the two deck repositories. |

Internal names still say "Kartei", the app's working title.

## Build

You need Xcode 26, [XcodeGen](https://github.com/yonaskolb/XcodeGen), rustup, `protoc`, the Android
SDK with NDK 29, JDK 17, and Python 3 with `genanki`, `Pillow`, `PyYAML` and `Pygments`.

```sh
# 1. Anki's source (AGPL), at the pinned commit, into spike/anki
core/ffi/fetch_anki.sh

# 2. The backend: XCFramework, Android .so, generated message code
core/ffi/build.sh

# 3. The course decks
cd content/courses
./sync_decks.sh && python3 build_decks.py && ./install_decks.sh
cd ../..

# 4a. Apple
cd apps/apple && xcodegen generate
xcodebuild -project Kartei.xcodeproj -scheme Kartei -destination 'platform=macOS' -derivedDataPath build build
open build/Build/Products/Debug/Bergmönch.app

# 4b. Android
cd apps/android && JAVA_HOME=/path/to/jdk17 ./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

The default signing is ad hoc, so no Apple developer team is needed for the Mac and the simulator.
For a device or TestFlight, see the comments at the top of `apps/apple/project.yml` and
`scripts/testflight.sh`. A signed Android release needs `apps/android/keystore.properties`
(see `apps/android/app/build.gradle.kts`).

## The Mac app

The same sources build a Mac app with its own shell: one resizable window, the three screens in the window
toolbar (also Command-1 to 3), Settings in their own window (Command-comma), File > Import Deck, and `.apkg`
files opened from the Finder or dropped on the window. Review is keyboard-first; Help > Keyboard Shortcuts
lists the keys, which are Anki's. The Mac-only code is in `apps/apple/Kartei/MacApp.swift`.

Local builds are ad hoc and not sandboxed. A release build (`scripts/testflight.sh --mac`) is signed with the
team and runs in the App Sandbox. It is Apple Silicon only, because `core/ffi/build.sh` builds the Rust core for
arm64 on the Mac.

## Tests

```sh
cd apps/apple && xcodebuild -project Kartei.xcodeproj -scheme Kartei -destination 'platform=macOS' -derivedDataPath build test
cd apps/android && ./gradlew :app:testDebugUnitTest
cd content/courses && python3 test_build.py
```
